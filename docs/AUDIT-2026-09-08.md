## 4. Dead / unused code

**Не доказано**, что какой-либо runtime-модуль `native_kernel/**` недостижим. Наивный граф `ast.Import` без учёта relative imports (`from .hashing import …`) ложно помечает пакетные модули как «никогда не импортированные». После ручной проверки:

- `native_kernel/postgresql_profile/hashing.py` импортируется из `adapter.py` (`from .hashing import …`).
- `native_kernel/postgresql_profile/history.py` импортируется из `replay.py`.
- `native_kernel/sqlite_profile/{adapter,models,replay,replay_models,hashing,runtime}.py` используются тестами и/или `__init__.py`.
- CLI в `tools/ai_context/`, `tools/conformance/`, `tools/profiles/`, `tools/evidence/`, `tools/operations/`, `tools/bpv1/` вызываются из `.github/workflows/*.yml` и/или `unittest`.
- Цепочка `validate_project_state.py` → `validate_project_state_post_adr0027.py` → `validate_project_state_d8.py` → `validate_project_state_history.py` (и аналоги freeze/reconciliation) **не orphan**: файлы читаются через `Path.read` + `exec` / подмена `__name__`, не через обычный `import`.

**Не доказано unused pip-deps:** единственный requirements-файл содержит только `psycopg[binary]>=3.3,<3.4`, который ставят P2/P3/P4/P5 CI. Lockfile приложения нет.

**Пустые/ожидаемо отсутствующие деревья (не «мёртвый код»):** `prototype/recovered/` отсутствует; `prototype/README.md` статус `BLOCKED / AUTHENTIC SOURCE NOT LOCATED`. Это согласовано с Issue #1 и `project-state.json` track H `NOT_FOUND_IN_ACCESSIBLE_SOURCES`.

**Curiosity Core:** совпадений `Curiosity` в `*.py` нет. RFC `docs/rfc/0001-curiosity-core-architecture.md` существует; runtime-кода нет. Это не unused export, а нереализованный RFC.

Итог: **orphaned Python module / unused export с доказательством не найден**. Ближайшее к «шуму» — near-duplicate файлов профилей (§5), не dead code.
